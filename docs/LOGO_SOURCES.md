# Linked service icons

The small icons identify external profile links; they are not the application logo and do not imply endorsement. All brands remain the property of their respective owners.

| Service | Bundled asset | Source |
| --- | --- | --- |
| VacList | `ui/logos/vaclist.ico` | `https://vaclist.net/favicon.ico`, declared by the site's manifest |
| CSRep | `ui/logos/csrep.ico` | `https://icons.duckduckgo.com/ip3/csrep.gg.ico`, cached site favicon; direct origin returned HTTP 403 during preparation |
| CSStats | `ui/logos/csstats.ico` | `https://csstats.gg/favicon.ico` |
| CSWatch | `ui/logos/cswatch.png` | `https://cswat.ch/favicon.png`, declared by the site's manifest |

These assets are served locally. Account cards do not contact the linked services until the user opens their links. Steam profile photographs and game art are loaded from Steam's CDN.

- SteamIDCheck: https://steamidcheck.com/favicon.svg (declared site favicon).
- Project logo: image provided by project owner Yusuf Kasapoglu; copied unchanged to `ui/logo.png`. The Windows icon is a format/size conversion of that image.
